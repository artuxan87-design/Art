# Сайт Евгения Артюшкина

Запуск: установить Node.js 20+, дважды щёлкнуть start.bat (или `npm start`). Сайт: http://localhost:3000, админка: http://localhost:3000/admin. Пароль админки создаётся при первом запуске и лежит в config.json.

Всё настраивается в админке (/admin): сайт и контакты, решения, услуги, кейсы, оплата с ключами банков, ставки партнёрки, пароль. Файлы content/*.json нужны только для первого заполнения базы. Оплата: docs/ПЛАТЕЖИ.md.

Тесты: `npm test`. Документы проекта: ТЗ.md, ЖУРНАЛ.md, ПАМЯТЬ.md/.

Публикация на хостинг: docs/ПУБЛИКАЦИЯ.md, файлы в папке deploy. Демо решения открывается по /demo/адрес-решения/.
